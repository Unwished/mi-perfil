# Repositorio - Mi perfil 
## Como ejecutar
### 1. Vincule este repositorio con su herramienta de edición de código preferida y clone el repositorio.
### 2. Abrá el terminal.
### 2.5. Asegurecé que esta en la carpeta correspondiente, en caso que no, use el comando "cd ..." reemplazando los tres puntos por el nombre de la carpeta que contenga este proyecto, preferiblemente "mi-perfil".
### 3. Escriba el comando "npm start".
### 4. En su celular, abrá la aplicación "Expo go".
### 5. Escaneé el código qr que aparece en la terminal con la herramienta que aparece en la aplicación.
### Eso sería todo, disfrute de la app.
